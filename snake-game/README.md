# Snake Game

A little project for me to learn cpp.

And it's also my first snake game.

## Dependencies

- Raylib 5.0

## Usage

1. Clone this project

2. Compile with `make`

3. Move the snake with `arrow keys` or `hjkl` (vim movements), key `r` to restart

## Known Issue

- If the snake is moving up, pressing key [left/right] then key down will cause the snake goes down
